# 丈量手帳

給磁磚行業務用的 iPad 丈量筆記本：在現場用 Apple Pencil 畫平面草圖、標尺寸、放衛浴與門窗符號，再匯出圖片交給製圖員建模。

👉 使用網址：https://fanxuan89222-ai.github.io/measure-notebook/

## 怎麼裝到 iPad
1. 用 **Safari** 打開上面的網址
2. 點右上角「分享」→「加入主畫面」
3. 主畫面會出現「丈量手帳」圖示，之後點它就像一般 App 一樣全螢幕使用

## 功能
- 草圖模式（現場隨手畫）／精畫模式（回辦公室描在草圖上）
- 畫筆按住會自動拉直、牆壁筆、尺寸標註、箭頭與框、文字、橡皮擦
- 內建衛浴、門窗、收納家電符號，可匯入照片存成自己的符號
- 圖層、照比例模式、紙張大小（無限／A4／A3）
- 文件庫：資料夾（可換顏色）、搜尋、最多 6 個分頁

## 資料存在哪裡
圖都存在**各自那台 iPad 的瀏覽器裡**，不會上傳到任何地方。
刪除 Safari 網站資料或換 iPad，圖就不見了，重要的圖請記得匯出。
